# Intro. to Philippine Criminal Justice System

A responsive educational website for CRIM 1.

## Files
- `index.html` — page structure/content
- `styles.css` — gold/black visual design, responsive layout, light/dark mode
- `script.js` — theme toggle, creator email list, scroll progress, back-to-top

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all three files.
3. Commit the changes.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. GitHub will provide your Pages URL.

## Note
The website is an educational project, not legal advice. Legal references should be checked against current official sources and applicable jurisprudence.
